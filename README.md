# Vibe-Coding-Kurs-Starter

Ein absichtlich kleines Projekt für den Neigungskurs: **Idee → Agent → ausprobieren → Git → GitHub → Pull Request**.

## Start

```bash
npm test
npm start
```

Dann `http://localhost:8000` öffnen.

## Erste Schüler-Challenge

Verändere mindestens drei Dinge mit einem Coding-Agenten. Beispiele: neue Aktivitäten, Punktestand, Timer, Animation, Dark Mode oder ein komplett anderes Thema.

## Git-Lernziele

1. Änderung ansehen (`diff`)
2. sinnvollen Commit machen
3. Branch für ein Experiment anlegen
4. Pull Request prüfen und mergen

> Keine persönlichen Daten, Passwörter oder API-Schlüssel in das Repo schreiben.
